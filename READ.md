# SecureMind 🛡️

**Платформа цифровой безопасности для школьников**

> SecureMind — интерактивная веб-платформа, которая обучает распознавать фишинг, мошенничество и киберугрозы через практические сценарии.
> Мы учим не правилам, а мышлению.


---

## О проекте

Число случаев интернет-мошенничества в Казахстане выросло на 26% (источник: 24.kz). Школьники — самая уязвимая аудитория: они не могут отличить фишинговое письмо от настоящего и не знают, как вести себя при социальной инженерии.

SecureMind решает эту проблему через **практику, а не теорию** — ученик попадает в реальную ситуацию, делает выбор и сразу получает объяснение ошибки.

## Возможности

- 🧪 **Диагностический тест** — определяет начальный уровень и слабые зоны
- 📚 **Микро-обучение** — короткие теоретические блоки с реальными примерами
- 🎮 **7 интерактивных сценариев** — симуляции почты, браузера, мессенджера, QR-сканера
- 🤖 **AI-функции** — генерация персональных фишинг-сценариев и план обучения
- 📊 **Аналитика прогресса** — радар компетенций, график динамики, тепловая карта
- 🏫 **Дашборд учителя** — мониторинг класса, назначение заданий, экспорт отчётов
- 🌐 **Двуязычность** — полный интерфейс на русском и казахском (RU / KZ)
- 📴 **Офлайн-режим** — работает без интернета после первого запуска (PWA)

## AI в SecureMind

Искусственный интеллект выполняет две ключевые функции:

**1. AI-генератор персональных фишинг-сценариев**
- Создаёт уникальное письмо для каждого ученика при каждом прохождении
- Анализирует профиль (имя, класс, слабые темы) и адаптирует сложность
- 70% писем — фишинг, 30% — безопасные (чтобы не угадывать)

**2. AI-анализ диагностики и персональный план обучения**
- Выявляет паттерны ошибок в тесте
- Генерирует план из 4 шагов: какие сценарии проходить и в каком порядке
- Персонализирует обучение вместо универсального подхода

## Технический стек

| Слой | Технология |
|------|-----------|
| Интерфейс | HTML5 + CSS3 + Vanilla JavaScript (ES6+) |
| Хранение данных | localStorage + IndexedDB |
| Офлайн | Service Worker + Cache API (PWA) |
| Графики | Chart.js |
| PDF-экспорт | jsPDF |
| AI | Anthropic Claude API |
| i18n | Кастомный JS-модуль (locales/ru.json, kz.json) |

Не требует фреймворков. Не требует сервера. Работает в любом браузере.

## Запуск

Проект не требует сборки или сервера:

```bash
# Просто открой в браузере
open index.html

# Или запусти локальный сервер (рекомендуется для Service Worker)
npx serve .
# или
python3 -m http.server 8080
```
